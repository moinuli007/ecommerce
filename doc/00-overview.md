# ০০ — প্রজেক্ট ওভারভিউ

## কী বানাচ্ছি

একটা সিঙ্গেল-ব্র্যান্ড অনলাইন স্টোর, যার পেছনে পূর্ণ ডাবল-এন্ট্রি হিসাব থাকবে।
প্রোডাক্ট, কাস্টমার, ইনভেনটরি — সবকিছুর হিসাব ভাউচারের মাধ্যমে অ্যাকাউন্টে যাবে,
অর্থাৎ যেকোনো মুহূর্তে ট্রায়াল ব্যালেন্স, লেজার স্টেটমেন্ট আর প্রফিট বের করা যাবে।

তিনটা সারফেস:

| সারফেস | পাথ | কী |
|---|---|---|
| **Storefront (web)** | `/` | কাস্টমার যা দেখে — ক্যাটালগ, কার্ট, চেকআউট |
| **Admin** | `/admin/*` | দোকান চালানোর প্যানেল — অর্ডার, স্টক, হিসাব, রিপোর্ট |
| **API** | `/api/v1/*` | JSON — মোবাইল অ্যাপ, এবং web/admin এর নিজের ডেটা সোর্স |

web আর admin এর প্রতিটি ডেটা API লেয়ারের মধ্য দিয়েই আসে — আলাদা কোনো ডেটা-পাথ নাই
(দেখুন [01-architecture.md](01-architecture.md) এর সিদ্ধান্ত D-04)।

## রেফারেন্স সাইট

<https://marlandmanor.store> — মেনজওয়্যার স্টোর (Shopify)। যেসব বৈশিষ্ট্য নকল করা হবে:

- **প্রোমো বার** — "Cash on Delivery All Over Bangladesh", "Free Delivery on Orders Over ৳3,000"
- **নেভিগেশন** — Collections ড্রপডাউন (All Shirts, Casual Shirts, Half Shirts,
  Denim Jeans Pants, Polo T-Shirts), সার্চ, অ্যাকাউন্ট, কার্ট (আইটেম কাউন্ট সহ)
- **হোম** — হিরো ব্যানার → New Arrivals গ্রিড → Bestsellers → Collection কার্ড
- **প্রোডাক্ট কার্ড** — ছবি, নাম, দাম (Tk), সেল দাম থাকলে কাটা রেগুলার দাম, "Choose" বাটন
- **ভ্যারিয়েন্ট** — সাইজ/কালার (তাই প্রোডাক্ট ও ভ্যারিয়েন্ট আলাদা টেবিল হবে)
- **ভাষা** — English / বাংলা টগল
- **ফুটার** — শপ লিংক, পলিসি (Privacy/Returns/Terms), About, Messenger/WhatsApp/email,
  সোশ্যাল, নিউজলেটার
- **কার্ট** — খালি অবস্থায় "Your cart is empty" + দ্রুত চেকআউটের জন্য লগইন প্রম্পট

বাংলাদেশি ই-কমার্সের যে বাস্তবতাগুলো হিসাবের ডিজাইনে ধরা হয়েছে:
**COD ই প্রধান পেমেন্ট** (তাই কুরিয়ার-রিসিভেবল লেজার), **কুরিয়ার সেটেলমেন্ট আলাদা ধাপ**,
**bKash/Nagad আর গেটওয়ে ফি**, **শিপিং চার্জ আলাদা আয়**।

## ফেজ ১-এ কী কী এসেছে

- `app/Core/` — DB (prepared statement), QueryBuilder, Model, Router, Request,
  Response, Message, Auth, Validator, View, Utility, Env, Autoloader
- `app/Enum/` — VoucherType (২১টি), LedgerType, AutoLedger (২১টি), AutoChart, MasterAccountType, TransactionType
- `app/Modules/Account/` — ৫টি মডেল, ৫টি সার্ভিস, ২টি API ক্লাস, ২টি কন্ট্রোলার, ৫টি ভিউ
- `app/Modules/Auth/` — লগইন (session + Bearer টোকেন), প্রোফাইল
- `app/Modules/Dashboard/` — অ্যাডমিন ড্যাশবোর্ড
- `database/` — ৯টি টেবিল, সিস্টেম চার্ট সিড, ইনস্টলার
- অ্যাডমিন UI — erp_saas ধাঁচের লেআউট (সাইডবার + টপ-রাইট প্রোফাইল ড্রপডাউন),
  ড্যাশবোর্ড, ভাউচার লিস্ট/এন্ট্রি/ডিটেইল, চার্ট অব অ্যাকাউন্টস, লেজার স্টেটমেন্ট, ট্রায়াল ব্যালেন্স
  — বিস্তারিত [06-admin-ui.md](06-admin-ui.md)
