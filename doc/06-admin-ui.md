# ০৬ — অ্যাডমিন UI

erp_saas এর অ্যাডমিন লেআউটের কাঠামো অনুসরণ করা হয়েছে, তবে কোনো এক্সটার্নাল
লাইব্রেরি ছাড়া — Bootstrap, jQuery, Feather, Select2 কিছুই লোড হয় না।
পুরো CSS/JS লেআউট ফাইলের ভেতরেই, আইকন ইনলাইন SVG।

## কাঠামো

```
┌────────────────────────────────────────────────────────────┐
│ [E] Ecommerce  ⟨⟩        [বাং] [🌙] [⛶]  [A] নাম ▾        │  header (fixed)
├──────────────┬─────────────────────────────────────────────┤
│ প্রধান        │  ড্যাশবোর্ড                                 │
│  ▸ ড্যাশবোর্ড │  ড্যাশবোর্ড › হিসাব › ভাউচার লিস্ট          │  page-header
│              │                                              │
│ হিসাব        │  ┌──────┐ ┌──────┐ ┌──────┐                │
│  ▸ ভাউচার    │  │ কার্ড │ │ কার্ড │ │ কার্ড │                │  content
│  ▸ নতুন      │  └──────┘ └──────┘ └──────┘                │
│  ▸ চার্ট      │                                              │
│              │                                              │
│ রিপোর্ট       │                                              │
│  ▸ ট্রায়াল    │                                              │
└──────────────┴─────────────────────────────────────────────┘
   sidebar              page-wrapper
```

**টপ বারের সব কন্ট্রোল ডান পাশে** (erp_saas এর `ul.nav.user-menu` এর মতো):
ভাষা টগল, লাইট/ডার্ক, ফুলস্ক্রিন, তারপর প্রোফাইল ড্রপডাউন।

**প্রোফাইল ড্রপডাউনে** — নাম + ইমেইল, তারপর "আমার প্রোফাইল" আর "লগআউট"
(লগআউট লাল)। erp_saas এ "Settings"ও আছে; সেটিংস পেজ ফেজ ৭-এ আসবে বলে
এখন মেনু থেকে বাদ — ডেড লিংক রাখা হয়নি।

> সাইডবার বাম পাশে, erp_saas এর মতোই। ডান পাশে চাইলে বলবেন —
> `.sidebar` আর `.page-wrapper` এর `left`/`margin-left` উল্টে দিলেই হবে,
> একটাই ফাইল (`resources/views/layouts/admin.php`)।

| কন্ট্রোল | কাজ | মনে রাখে? |

| ☰ (মোবাইল) | সাইডবার ড্রয়ার খোলে, ব্যাকড্রপে ক্লিকে বন্ধ | — |

| ⛶ | ফুলস্ক্রিন টগল | — |
| প্রোফাইল ▾ | ড্রপডাউন; বাইরে ক্লিক বা `Esc` এ বন্ধ | — |

থিম ডিফল্টে সিস্টেম সেটিং অনুসরণ করে (`prefers-color-scheme`); 🌙 চাপলে
`data-theme` অ্যাট্রিবিউট বসে ম্যানুয়াল পছন্দ জিতে যায়।

ব্রেকপয়েন্ট **900px** — এর নিচে সাইডবার ড্রয়ার হয়ে যায়, প্রোফাইলের নাম লুকায়।

## মেনু

মেনু `app/Core/Menu.php` এ — কোডে, DB-তে নয় (রাউট যেহেতু কোডে, দুটো
কখনো আলাদা হয়ে যাবে না)।

```php
['label' => 'Voucher List', 'path' => '/admin/vouchers', 'icon' => 'list', 'match' => 'exact'],
```

| ফিল্ড | মানে |
|---|---|
| `label` | মেনুতে যা দেখাবে |
| `path` | `APP_URL` এর পরের অংশ |
| `icon` | `Menu::icon()` এর নাম (নিচে তালিকা) |
| `match` | `exact` না দিলে প্রিফিক্স ম্যাচ — `/admin/vouchers/12` ও প্যারেন্টকে active দেখাবে |
| `superAdminOnly` | `true` হলে শুধু Super Admin দেখবে (`Auth::isSuperAdmin()`) — যেমন "Admin Users", [13-auth-and-user-management.md](13-auth-and-user-management.md) §৪ |

`Menu::locate()` ব্রেডক্রাম্বের জন্য সবচেয়ে নির্দিষ্ট মিল বের করে।

**নতুন মডিউল যোগ করলে** `Menu::admin()` এ একটা গ্রুপ/আইটেম যোগ করবেন —
লেআউট নিজে থেকেই রেন্ডার করবে, লেআউট ফাইল ছোঁয়ার দরকার নাই।

উপলব্ধ আইকন: `home` `grid` `book` `list` `plus` `layers` `bar-chart` `scale`
`user` `settings` `power` `wallet` `trend-up` `trend-down` `in` `out`
`tag` `box` `folder` `sliders` `ruler` `truck` `chevron` `menu` `check` `alert`

## ড্যাশবোর্ড

`/admin` — ডেটা `Dashboard\Api\DashboardApi::index()` থেকে
(HTTP-তেও একই: `GET /api/v1/dashboard`)।

| ব্লক | কী দেখায় |
|---|---|
| সতর্কতা ব্যানার | ট্রায়াল ব্যালেন্স না মিললে লাল ব্যানার |
| ৬টা স্ট্যাট কার্ড | ক্যাশ · ব্যাংক+মোবাইল · পাওনা · দেনা · এ মাসের বিক্রি · এ মাসের খরচ |
| বিক্রির চার্ট | শেষ ১৪ দিনের দৈনিক বিক্রি (ইনলাইন বার চার্ট, কোনো চার্ট লাইব্রেরি নাই) |
| সাম্প্রতিক ভাউচার | শেষ ৮টা |
| আটকে থাকা টাকা | কুরিয়ারে COD · গেটওয়েতে জমা · স্টকের মূল্য |
| হিসাবের সারাংশ | মাস্টার অ্যাকাউন্ট অনুযায়ী মোট |
| বড় ব্যালেন্স | সবচেয়ে বড় ৮টা লেজার |
| হিসাবের স্বাস্থ্য | ট্রায়াল ব্যালেন্স Dr/Cr + সক্রিয় লেজার সংখ্যা |

সব সংখ্যা `Account\Services\AccountSummary` থেকে আসে, যেটা **read-only** —
`LedgerAccounts::findSystemLedger()` ব্যবহার করে, `systemLedger()` নয়।
ফলে ড্যাশবোর্ড খুললেই চার্টে খালি লেজার তৈরি হয়ে যায় না।

ফেজ ৩-এ অর্ডার এলে এখানে আজকের অর্ডার, পেন্ডিং শিপমেন্ট, স্টক অ্যালার্ট যোগ হবে।

## শেয়ার্ড CSS ক্লাস

ভিউ লেখার সময় এগুলো ব্যবহার করবেন — লেআউটেই ডিফাইন করা:

| ক্লাস | কী |
|---|---|
| `.card` / `.card-title` | সাদা বক্স + শিরোনাম |
| `.msg` `.msg-e/s/w/i` | মেসেজ ব্যানার (রেসপন্সের `m` এর টাইপ কোডের সাথে মেলে) |
| `.scroll` | ভেতরের টেবিল আলাদাভাবে হরাইজন্টাল স্ক্রল করবে |
| `table` `td.num` | টেবিল; `.num` ডান-অ্যালাইন + tabular সংখ্যা |
| `form.filters` | ফিল্টার বার (ফ্লেক্স, র‍্যাপ) |
| `button` / `.btn` / `.ghost` | বাটন |
| `.muted` `.empty` `.pos` `.neg` | ধূসর টেক্সট · খালি অবস্থা · সবুজ · লাল |

**পেজের ডান দিকে অ্যাকশন বাটন** দিতে কন্ট্রোলার থেকে `pageActions` কি-তে
HTML পাঠাবেন — `page-header` এর ডান দিকে বসবে।

## নতুন অ্যাডমিন পেজ যোগ করার ধাপ

```php
// ১. Api — payload array
final class ProductApi {
    public static function index(): array { /* ... */ return Response::payload(); }
}

// ২. Controller — একই Api মেথড, তারপর ভিউ
final class ProductController {
    public static function index(): string {
        Response::reset();
        $payload = ProductApi::index();
        return View::layout('layouts/admin', 'Catalog::product/list', [
            'title'    => 'প্রোডাক্ট',
            'products' => $payload['products'] ?? [],
            'messages' => $payload['m'] ?? [],
        ]);
    }
}

// ৩. routes/api.php + routes/admin.php এ রাউট
// ৪. Menu::admin() এ আইটেম
// ৫. app/Modules/Catalog/Views/product/list.php
```

⚠ ভিউতে ভ্যারিয়েবল পাঠানোর সময় মনে রাখবেন: `View::render()` ভেতরে
`extract(..., EXTR_SKIP)` চালায়, তাই ভিউ-স্কোপে সেগুলোই আসে যেগুলোর নাম
`$__viewFile` / `$__viewData` এর সাথে মেলে না। বাকি সব নাম নিরাপদ।
